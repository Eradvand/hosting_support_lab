. بررسی رکورد MX ایمیل

رکورد MX مشخص می‌کند ایمیل‌های یک دامنه به کدام Mail Server ارسال شوند.

دستور:




nslookup -type=MX gmail.com
در تست اولیه، درخواست از DNS پیش‌فرض سیستم با Timeout مواجه شد.

سپس با استفاده از DNS عمومی گوگل دوباره بررسی شد:
nslookup -type=MX gmail.com 8.8.8.8
این بار رکوردهای MX با موفقیت دریافت شدند.

نتیجه:

اگر یک Query DNS با یک DNS Server پاسخ ندهد، می‌توان با DNS Resolver دیگری بررسی کرد تا مشخص شود مشکل از خود دامنه است یا سرویس DNS مورد استفاده.
