# WordPress Troubleshooting

## سایت WordPress از چه بخش‌هایی تشکیل می‌شود؟

- Website files
- PHP
- Database
- Web server
- Domain
- DNS
- SSL

## مشکلاتی که باید بررسی کنم

### Website does not open

Possible checks:

- Domain and DNS
- Server status
- Website files
- PHP
- Database
- SSL

### HTTP 500

Possible checks:

- PHP error
- Plugin or theme
- .htaccess
- PHP version
- Server error log
